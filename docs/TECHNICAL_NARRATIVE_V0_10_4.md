# Website Prototype 0.10.4 — Technical Narrative Calibration

Status: **PUBLIC RHETORIC CALIBRATED / INTERNAL AUTHORITY GATE RETAINED**

## Court decision

The v0.10.3 homepage over-exposed its epistemic bookkeeping. Phrases such as `not locked`, `withheld`, `public simplification`, and repeated `under review` labels were accurate but made the public page sound like an audit report instead of a project with direction.

v0.10.4 separates the two layers:

- **Public page:** explain the system, the roadmap, the current build, and the ambition.
- **Repository docs / release gate:** preserve candidate-vs-confirmed distinctions and block accidental publication of exact unconfirmed stack details.

This is a rhetoric mutation, not a relaxation of the truth standard.

## Public narrative

`Build the environment → preserve an actor contract → learn from human play → self-play → return to the device`

The page may state this as project direction without repeatedly interrupting itself with implementation caveats. Exact model/library names, dimensions, hyperparameters, and detailed blocker payloads remain gated internally.

## Colt placement

`Colt` is removed from the hero metadata. The hero describes Kodo as a system. Colt appears later in an ambition section:

> Start with Colt. Don’t stop there.

This treats Colt as the first proving ground rather than the identity of the entire project.

## Real-media landing zone

The primary hero figure remains the real-media landing zone. Until a publishable Kodo capture is supplied, it renders the existing system schematic. The visible fallback label is now `SYSTEM SCHEMATIC`; the stronger provenance distinction remains in `media-manifest.js` and media-intake documentation.

## Disclosure boundary retained

Do not publish as confirmed without a later NPLUS lock:

- PufferRL / MAPPO / PPO / V-trace / GAE
- YOLOv8 / minitouch
- Transformer / LSTM
- observation or critic dimensions
- action cardinalities
- gamma/lambda or numerical tuning targets
- detailed G1–G7 blocker payloads

## Skill-Workshop audit roles

- **Design:** public page should express motion and ambition, not audit anxiety.
- **Implementation:** candidate details remain absent from public HTML.
- **Skeptic:** ambition is phrased as direction, never as achieved capability.
- **Authority:** exact architecture remains internally gated.
- **Handoff:** future real media can replace the schematic without rewriting the page structure.
