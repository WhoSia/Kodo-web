OVERVIEW / SYSTEM PREMISE

Build the world. Then learn inside it.

Kodo treats the environment as part of the learning system: implement the mechanics, expose a controllable state, train agents against it, then close the loop through visual observation.

STACK / SHARED ACTOR LOOP

One actor loop, two ways in.

In simulation, Kodo reads structured state. On device, perception reconstructs the same actor-facing contract. From there the loop stays recognizable: observe, represent, remember, decide, act.
